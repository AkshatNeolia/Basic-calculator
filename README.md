# Basic Calculator

A simple GUI-based calculator built using Python and Tkinter.

## Features
- Basic arithmetic operations (+, -, *, /, %)
- Parentheses support for expressions
- Clear button to reset the input
- Green '=' button for evaluating expressions
- Responsive UI with button-based input

## Technologies Used
- Python
- Tkinter

## Installation
1. Clone the repository:
   ```sh
   git clone https://github.com/AkshatNeolia/Basic-Calculator.git
   cd Basic-Calculator
   ```
2. Run the script:
   ```sh
   python calculator.py
   ```

## Usage
- Click the buttons to enter an expression.
- Press `=` to evaluate.
- Press `C` to clear the input.
